# Picnic Fun Zone — Premium Frontend Edition

Open `index.html` locally or upload this folder contents to GitHub Pages. No build tools or database required.

## Updates
- Responsive visual polish across all existing HTML pages
- Navigation, page links and brand consistency
- Booking buttons now open the contact enquiry page (no fake authentication)
- Contact form prepares an email in the visitor’s email application; it does **not** send or save data automatically
- Removed missing Firebase dependencies
- Added keyboard focus and reduced-motion styles

## Before publishing
Replace placeholder contact email, phone number and address with your real business details. The static contact form depends on a working email app and inbox. Real reservations, payments and account login require a backend or external service.
